# Platform References

Platform documents explain how a runtime implements the shared Fresnica contracts.

Every platform starts with the five common documents in [`../README.md`](../README.md). Platform references may choose local SDKs, storage, UI and system integration, but must not redefine Normative Capability semantics or Fresnica Core security invariants.
